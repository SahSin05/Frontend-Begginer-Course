# What React is and project setup

React is a JavaScript library for building user interfaces from reusable components. Use a modern starter such as Vite with its React + TypeScript template.

Example setup:
```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm run dev
```
Open the local URL shown in the terminal.
