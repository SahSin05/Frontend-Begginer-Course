# Mini-project: course dashboard

Build a small dashboard that combines the React skills from this module. It should display courses, allow a user to add a course, and show useful empty/loading/error states if you load data from an API.

Example course type:
```tsx
type Course = {
  id: number;
  title: string;
  completed: boolean;
};
```

## Problems to solve

1. Build a dashboard that renders course cards from data, supports adding a course, and marks a course as completed.

2. Add a course search input and filter the displayed courses. Keep components small and use TypeScript types for your data and props.
