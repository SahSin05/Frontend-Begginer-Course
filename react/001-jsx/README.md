# JSX

JSX lets you describe UI using HTML-like syntax inside JavaScript/TypeScript. Use `{}` to insert expressions. Return one parent element (or a fragment).

Example:
```tsx
function Welcome() {
  const name = "Asha";
  return <h1>Welcome, {name}</h1>;
}
```
