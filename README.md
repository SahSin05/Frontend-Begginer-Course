# Frontend Beginner Course

A practical, exercise-first course for a college student preparing for a fresher frontend developer role.

## Modules and order
1. `typescript/` — essential JavaScript foundations taught with TypeScript types.
2. `html-css/` — semantic HTML, forms, layout, responsive styling, and accessibility basics.
3. `react/` — React with TypeScript, state, forms, effects, API data, and a small dashboard project.

## How to study
- Complete folders in numeric order.
- Read the short explanation and type the example yourself.
- Solve both problems without copying a solution.
- Test the result in the browser or terminal as appropriate.
- Move on only when both problems work and you can explain your code.
- If stuck, break the problem into smaller steps and consult official documentation.

## Suggested tools
- A current version of Node.js (LTS)
- Visual Studio Code or another code editor
- A modern browser with developer tools
- Git (useful for saving progress; not required for the first lessons)

## Important notes
- The React module uses TypeScript.
- The TypeScript module includes the JavaScript fundamentals needed for these exercises; a separate JavaScript course is intentionally not included.
- Exercise solutions are intentionally not provided. The goal is to build independent problem-solving ability.
- For React setup, follow the Vite instructions in lesson `000-what-react-is-and-project-setup`.

## Completion standard
The student should be able to build and explain a responsive profile page and a small React course dashboard that handles user input and displays data.
