# Operators and expressions

Use arithmetic (`+ - * / %`), comparison (`=== !== > <`), and logical (`&& || !`) operators to calculate and make decisions.

Example:
```ts
const price = 250;
const quantity = 3;
const total = price * quantity;
const eligibleForFreeDelivery = total >= 500;
```
