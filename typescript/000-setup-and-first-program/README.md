# Setup and your first program

TypeScript adds types to JavaScript and helps catch mistakes before code runs. You write `.ts` files and use the TypeScript compiler to produce JavaScript.

Example:
```ts
const greeting: string = "Hello, student";
console.log(greeting);
```
Try it: install Node.js, create a project, install TypeScript, and run `npx tsc --init`. Compile a file with `npx tsc`.

## Problems to solve

1. Create `hello.ts` that prints your name and a one-line career goal.

2. Create `intro.ts` with three separate console messages: your name, course name, and today's learning goal. Compile and run it.
