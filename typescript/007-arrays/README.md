# Arrays

Arrays store ordered collections. Type them as `string[]`, `number[]`, or `Array<Type>`. Access items by index; the first index is `0`.

Example:
```ts
const scores: number[] = [72, 85, 91];
console.log(scores[0]);
scores.push(88);
```
