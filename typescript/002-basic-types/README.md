# Basic types

Common types are `string`, `number`, `boolean`, and `null`/`undefined`. TypeScript can infer a type when the initial value makes it clear.

Example:
```ts
const studentName = "Asha"; // string inferred
const semester: number = 3;
const isEnrolled: boolean = true;
```
