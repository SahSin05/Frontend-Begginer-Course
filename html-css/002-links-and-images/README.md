# Links and images

Use `<a>` for navigation and `<img>` for images. Always provide useful `alt` text for meaningful images.

Example:
```html
<a href="https://example.com">Visit the website</a>
<img src="campus.jpg" alt="Main college building">
```

## Problems to solve

1. Add links to two useful learning websites; make one open in a new tab safely using `target="_blank"` and `rel="noopener noreferrer"`.

2. Add an image to your page with descriptive alt text.
