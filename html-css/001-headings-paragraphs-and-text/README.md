# Headings, paragraphs, and text

Use headings to describe page sections in a logical hierarchy. Use paragraphs for normal text and `strong`/`em` for meaningful emphasis.

Example:
```html
<h1>Student Portal</h1>
<h2>Announcements</h2>
<p><strong>Notice:</strong> Exams begin next week.</p>
```

## Problems to solve

1. Create a college profile page with one `h1`, two `h2` headings, and paragraphs under each.

2. Write a short announcement using `strong` and `em` appropriately.
