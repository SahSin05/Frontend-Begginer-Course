# HTML document structure

HTML gives a webpage its structure. A page normally starts with a doctype, an `html` element, metadata in `head`, and visible content in `body`.

Example:
```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, world!</h1>
</body>
</html>
```
