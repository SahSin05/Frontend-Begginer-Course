# Colors, typography, and units

CSS controls visual presentation. Use readable contrast, a small consistent type scale, and relative units such as `rem` for scalable sizing.

Example:
```css
body { font-family: Arial, sans-serif; color: #222; }
h1 { font-size: 2rem; color: #243b53; }
p { line-height: 1.6; }
```
