# Mini-project: responsive student profile

Combine your HTML and CSS skills to build a small, responsive profile page. Include semantic structure, a short introduction, skills, links, and a contact form. Avoid adding JavaScript at this stage.

Example starting point:
```html
<main class="profile">
  <section>
    <h1>Your Name</h1>
    <p>Frontend developer in training.</p>
  </section>
</main>
```

## Problems to solve

1. Build the profile page with semantic HTML, a skills list, and links to two projects or learning resources.

2. Style it for mobile and desktop. Check keyboard focus, image alt text, and form labels before considering it complete.
