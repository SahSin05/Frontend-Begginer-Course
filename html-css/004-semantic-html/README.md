# Semantic HTML

Semantic elements describe the purpose of content. Prefer `header`, `nav`, `main`, `section`, `article`, and `footer` over using `div` for everything.

Example:
```html
<header><h1>Campus News</h1></header>
<main>
  <article><h2>Science Fair</h2><p>Event details...</p></article>
</main>
<footer>Contact the college</footer>
```

## Problems to solve

1. Build a page layout with header, navigation, main content, and footer using semantic elements.

2. Create two news articles inside `main`, each with its own heading and paragraph.
