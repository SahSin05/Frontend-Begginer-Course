# Forms and inputs

Forms collect user input. Use labels connected to inputs with matching `for` and `id` values. Choose appropriate input types.

Example:
```html
<form>
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>
  <button type="submit">Register</button>
</form>
```
