# Display and Flexbox

Flexbox is useful for arranging items in a row or column. Use `display: flex`, `gap`, `justify-content`, and `align-items` for common layouts.

Example:
```css
.navigation {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
}
```
