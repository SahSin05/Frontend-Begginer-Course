# CSS Grid

Grid is useful for two-dimensional layouts with rows and columns. Use `grid-template-columns` and `gap` to define the layout.

Example:
```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```
