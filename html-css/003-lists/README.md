# Lists

Use unordered lists for items without a sequence and ordered lists when order matters.

Example:
```html
<h2>Skills</h2>
<ul><li>HTML</li><li>CSS</li></ul>
<ol><li>Plan</li><li>Build</li><li>Test</li></ol>
```

## Problems to solve

1. Create an unordered list of five skills you want to learn.

2. Create an ordered list describing the steps to submit a college assignment.
