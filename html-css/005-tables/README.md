# Tables

Use tables for genuinely tabular data, not for page layout. Include header cells with `th` and associate them with columns.

Example:
```html
<table>
  <tr><th>Subject</th><th>Credits</th></tr>
  <tr><td>Web Design</td><td>4</td></tr>
</table>
```
